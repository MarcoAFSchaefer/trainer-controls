# Differences from the unmodded game

Trainer Controls replaces how inputs reach the game. It does not change the game.

## Game data and rules

Nothing. No species, moves, items, maps, text, trainers, encounters or battle rules are added or changed.

## Input

- **The game's own key table is bypassed.** While the mod is on, only the bindings on its controls screen press the game's buttons and functions. A control you remove there is really gone until you bind it again.
- Mouse buttons, the mouse wheel, gamepad triggers and both sticks can be bound, which the game's own settings do not offer.
- **Field shortcuts** (Cut, Surf, Fly, Strength, Flash, Rock Smash, Waterfall, Dig, Teleport, Sweet Scent, Bicycle, Itemfinder, VS Seeker) on one input each. A shortcut goes down the same path as the game's menu, so it works only when the menu would offer it: the party needs the move, the badge and the right place.
- F8 opens the controls screen when nothing else is bound to it.

## Screen

A controls screen over the game, and a **Controls** panel in Trainer Desk when that mod is installed.

## Saves

The save file is not read or written. Bindings are kept in the mod's own cache.

## Turning it off

Disable the mod and the game's own controls are back as you left them. Nothing is left in the save.
